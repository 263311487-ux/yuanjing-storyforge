# Provider adapter contract

The core contract is implemented in `ai_comic_drama/providers.py`. An adapter exposes `capabilities()`, `estimate(manifest)`, `submit_shot(shot, run_id)`, and `poll(job_id)`. The runner persists state after every shot in JSON and enforces `budget.max_attempts` and `budget.max_shot_attempts`. A provider adapter must also document its download and evidence format, timeout behavior, and whether its integration has been exercised against a live account.

Use idempotent run IDs, preserve provider evidence and timestamps, retry rate limits with backoff, stop at the manifest budget, and never print credentials. Planning and QA work offline without an adapter. The bundled MockProvider is the only fully runnable adapter in this release. `SeedanceCLI` is an explicit opt-in command adapter; this release has no claim of a successful live paid submission, polling, download, or provider-side cost reconciliation. It applies bounded subprocess timeouts. A submission timeout is recorded as `unknown` because the provider may have accepted the request; the runner will not automatically resubmit an unknown shot. Resolve it against provider history before manually editing run state.

The Seedance adapter persists only task IDs, statuses, return codes, boolean artifact-presence metadata, and coarse error categories. It does not persist prompts, raw provider output, signed media URLs, or full command arguments in run state. Keep provider CLI logs private and review their contents before sharing them.
